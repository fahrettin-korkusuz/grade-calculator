
# Not Ortalaması Hesaplama Sistemi

Python kullanılarak geliştirilmiş, öğrencilerin ders
notlarını ve genel not ortalamalarını hesaplayan
bir konsol uygulamasıdır.

## Projenin Özellikleri

- Öğrenci ve ders bilgilerinin alınması
- Vize ve final notlarının hesaplanması
- Harf notunun belirlenmesi
- Geçti veya kaldı durumunun belirlenmesi
- Birden fazla ders eklenebilmesi
- Genel not ortalamasının hesaplanması

## Kullanılan Teknolojiler

- Python 
- Visual Studio Code

## Kullanılan Python Konuları

- Değişkenler ve veri tipleri
- Fonksiyonlar (def, return)
- Koşul ifadeleri (if, elif, else)
- While döngüsü
- Listeler
- Kullanıcıdan veri alma (input)
- Matematiksel işlemler

## Not Hesaplama Sistemi

- Vize ağırlığı: %40
- Final ağırlığı: %60
- Geçme notu: 60

Not aralıkları örnek olarak belirlenmiştir.
Genel ortalama hesaplanırken dersler eşit ağırlıklıdır.
Program geçerli not girişleriyle çalışmaktadır.

## Programı Çalıştırma

Terminal üzerinden aşağıdaki komutu çalıştırın:

`python main.py`
